# AS Tech — Assistência Técnica de Celulares

Landing page da AS Tech, assistência técnica de celulares em Salvador - BA.

Site estático em HTML, CSS e JavaScript, sem dependências: basta abrir o `index.html` no navegador.

## Estrutura

- `index.html` — página
- `css/styles.css` — estilos
- `js/main.js` — interações (menu, animações, links do WhatsApp)
- `assets/fotos/` — fotos do topo e dos serviços

## Fotos dos serviços

Salve em `assets/fotos/` com estes nomes (aparecem sozinhas no card):
`servico-tela.jpg`, `servico-bateria.jpg`, `servico-conector.jpg`, `servico-placa.jpg`, `servico-software.jpg`, `servico-diagnostico.jpg`.
